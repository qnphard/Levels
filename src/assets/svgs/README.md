# SVG assets for Rive

## Pipeline

1. **Discover** — Use the Cursor browser MCP or sites with raw `.svg` URLs.
2. **Fetch** — Use `web_fetch` on a direct SVG URL, or save a file into this folder.
3. **Import into Rive** — Rive MCP `import_svg` with `path` (this directory) or `svgString`.
4. **License** — Only use SVGs you have rights to; keep attribution when required.

`stickman.svg` is a minimal hand-drawn figure for this app (no external asset).
